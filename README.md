# SaaSScout — starter MVP

This is a simple static starter website for discovering AI tools and workflow automation software.

## Included
- Responsive English landing page
- Three sample software listings
- Client-side search/filter
- Affiliate disclosure placeholder
- Demo click counter stored only in the visitor's browser

## Important limitations
- This is a visual/static starter, not a production affiliate platform.
- The demo click counter is not shared across visitors and is not analytics.
- No affiliate tracking IDs, affiliate-network API, admin login, database, commission reporting, or automatic publishing are included.
- Replace outbound URLs with your own approved affiliate URLs only after the relevant affiliate program approves your account.
- Keep a clear affiliate disclosure wherever affiliate links appear.

## Deploy
You can publish `index.html` as a static site using Cloudflare Pages or another static hosting provider. For Cloudflare Pages, create a project connected to this GitHub repository and use the repository root as the build output directory; no build command is needed.

## GitHub upload from iPhone
Extract the ZIP in the iPhone Files app, then in your GitHub repository use **Add file → Upload files** and select `index.html` (and optionally `README.md`). Commit the files to the `main` branch.
